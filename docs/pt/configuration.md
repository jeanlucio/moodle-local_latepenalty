# ⚙️ Configuração

Ao criar ou editar qualquer atividade, uma seção **Penalidade por Atraso** aparece no formulário com estes campos:

| Campo | Descrição |
|-------|-----------|
| **Habilitar penalidade progressiva** | Ativa a regra para esta atividade |
| **Desconto diário (%)** | Percentual descontado por dia de atraso (0–100) |
| **Desconto máximo (%)** | Limite superior para o desconto total (0–100) |
| **Desconto calculado sobre** | De qual nota sai a porcentagem: a **nota obtida** (padrão) ou a **nota máxima** (os mesmos pontos para todos) |

O desconto máximo deve ser maior ou igual ao desconto diário.
