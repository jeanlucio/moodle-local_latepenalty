# ⚙️ Configuration

When creating or editing any activity, a **Late Penalty** section appears in the settings form with these fields:

| Field | Description |
|-------|-------------|
| **Enable progressive penalty** | Activates the rule for this activity |
| **Daily penalty (%)** | Percentage deducted per day late (0–100) |
| **Maximum penalty (%)** | Upper bound for the total deduction (0–100) |
| **Penalty applies to** | Which grade the percentage is taken from: the **grade obtained** (default) or the **maximum grade** (the same points for every student) |

The maximum penalty must be greater than or equal to the daily penalty.
